# Painel de estudo – Ciência da Computação (UFPel, Edital 28/2026)

Página estática com os 10 pontos do programa, os tópicos balizadores previstos, o cronograma até a prova e os links dos materiais abertos.

Publicada pelo GitHub Pages em https://emanuelqueiroga.github.io/concurso-ufpel-cc-painel/

O progresso (itens marcados e autoavaliação) fica salvo no navegador de cada aparelho. Para levar o progresso a outro aparelho, use o botão “Copiar link com meu progresso” e abra o link lá.

Os itens são uma previsão, não um documento oficial da banca.
