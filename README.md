# Painel de estudo – Concurso UFPel, Edital 28/2026, Ciência da Computação

Painel publicado em https://emanuelqueiroga.github.io/concurso-ufpel-cc-painel/, com os 100 balizadores previstos, o cronograma, o progresso de estudo e os links para as páginas de cada ponto, os resumos-modelo, o documento de balizadores e os materiais abertos (repositório `concurso-ufpel-cc-estudo`).

Para ter a sua própria versão, siga a seção "Como criar sua própria versão" do README do repositório `concurso-ufpel-cc-estudo`. Em resumo: crie os dois repositórios com os mesmos nomes na sua conta, envie os arquivos e ative o GitHub Pages neste (Settings → Pages → Deploy from a branch → `main` / `/ (root)`). Os links do painel passam a apontar para os repositórios de quem publicou a cópia.

O progresso fica salvo no navegador (localStorage) de cada aparelho e pode ser levado a outro aparelho pelo link de progresso.
